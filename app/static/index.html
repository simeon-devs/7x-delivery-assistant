How it holds

Code decides if.
The model decides what to say.

The guardrails are not instructions in a prompt. They are computed from the shipment file before any conversation exists, and re-checked at the moment of the write.

01

It knows nothing

No shipment data reaches the system prompt. The assistant cannot answer from context, so it has to call a tool to learn anything at all.

02

It is never told the rules

Nothing it sees says whether an action is permitted. It finds out by attempting, and the gate answers with a sentence and a case number.

03

One door, always logged

Every write passes through one function that re-reads the record, checks the gate and writes the trace. refused · 389.18 AED due on delivery

Be clear about it

What is real,
and what is not.

Real

The agent, the two actions, the guardrails and the database writes. After a conversation, a row is genuinely different.

The cleaning layer, the reconciliation, and every number on this page. 866 in equals 8 test records, 18 superseded duplicates and 840 clean, checked on every run.

Not real

Shipment records are synthetic, supplied with the assignment.

The WhatsApp channel is simulated. It is not connected to the WhatsApp Business API and no SMS is ever really sent. The verification step shows its own code on screen and says so.
